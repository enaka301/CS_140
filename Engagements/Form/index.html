Questions and Answers

The form tag has an "action" attribute. What does it do?
Action processes the form and it's contents serverside.
The form tag has a "method" attribute. What does it do?
Method is for http methods. This is usually GET and POST methods.
What is the difference between a "POST" and a "GET"?
GET sends the data directly to the url. POST sends the data through the http data instead of the url. It is more safe than GET because nothing is exposed in the url.
How do you fill in a form control with a pre-set value, and how is that different from a placeholder? Answer for each of these: text box, textarea, select box, checkbox, and radio button.
  • Text Box
  • To pre-set a value use the "value" attribute to send actual data. Placeholder is used to hint the user on what to type.
  • Text Area
  • A pre-set value is usually what is automatically submitted by default. A placeholder attribute holds the value to display in the text box.
  • Select Box
  • Pre-set values is made by putting "selected" in the tag area for an <option> tag. After some research, Select Box does not have a placeholder.
  • Check Box
  • Like the select box, the check box does not have a placeholder value tag. But it does have a pre-set value by using the "checked" attribute which acts as a boolean.
  • Radio Button
  • Just like the check box, "checked" can be used for the radio button. It does not have a placeholder attribute.
In conclusion, a pre-set value is the default display for a value and a placeholder is the hint for the user.
