When do you use a table?
Use a table to display information for things such as a menu, course catalog, schedule, etc. Use it for organizing items or content into a table.
When do you not use a table?
Things such as brochures, books, shopping sites, and web pages that display a lot of pictures would not need a table. I'd like to think that a table is to help the user get info quickly, not draw them in.
When do you need to do extra work for table accessibility?
When a table has complex content or things that people with screen readers may find difficult to read, extra work is needed.
