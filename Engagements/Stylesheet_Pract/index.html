Questions and Answers

  1. Explain the difference between inline, embedded, and external CSS.

    • Inline CSS is where the style is added next to the tag of a specific HTML block.

    • Embeded CSS is where the style is added in the head portion of the index.html file. It can manage the style for the site.

    • External CSS is where the style is in a different file all together. The style is very reusable since any files in the directory can access it.

  2. Explain why you should only use external CSS.

    • External CSS is what is used the most today. It is very reusable and easy to undrestand if someone were to look at it. EExternal CSS also helps with organization of files.

  3. What is a selector used for?

    • A selector is used to "select" a specific tag that needs to be styled. For example:

    • 
                        h4 {
                            color: blue;
                        }

      In this case, h4 is the selector. Any contents that have the h4 tag would then turn blue.
