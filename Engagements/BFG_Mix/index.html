Questions and Answers
Why is the viewport meta tag important?
It defines how mobile users are able access the site and the dimensions of the pages on their phones. It basically helps with scaling.
How can you adjust the CSS for printing?
Use at the bottom of the stylesheet @media to only allow certain parts of your html to be visible during printing.
When would you want to adjust the CSS for printing?
Adjusting the CSS for printing should be strictly done fr sites that print coupons or images. Otherwise it is optional.
