Questions and Answers

What are different ways to style your form?
You can use css, html tags, :focus tags in the css, and use tags that are specific to inputs and labels such as id, name, type, class, value, and placeholder.
Why does the professor like to use flex?
I think I remember him saying that flex is able to move more freely with the window dimensions.
What makes for a good mobile form?
A good mobile form has @Media in the css file. This allows the browser to tell the page to change according to window dimensions. Here you can specify what the page should look like on mobile. It should be easy to click and be scrollable with all the content in the middle.
