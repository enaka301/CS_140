Questions and Answers
Why do we need a viewport meta tag?
A viewport meta tag to tell the browser how to size the page.
When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?
CSS is cascading styling. So, whichever was added to the stylesheet last overrides the top.
How do you change the CSS for a web page displayed on a phone?
You can use the @media tag in the css and specify the breakpoints of a screen in dev mode to change the css for a web page on a phone.
Pick a website you use on your phone. Name two things it changes on mobile compared to desktop.
Button placement changes and the menu sidebar is hidden so that the main content is viewed.
What width did you choose for your breakpoint, and why?
I chose 644 since that was the width where the images didn't change into a single column. At the same time it still allowed for two columns.
