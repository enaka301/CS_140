Answers to Questions

    Types of ways to select an item

  • What is the difference between an ID and a Class?
    • ID is a unique identifier for a styled tag. Class is also an identifier but multiple tags can use it.
  • What are the different ways to select a color?
    • In css, you can either type the color's name or select via VScode the color through the color selector.
  • What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?
    • DIV tags are used to group tags together for isolated styling. It can be placed in the header, main, or footer.
    • HEADER is mainly found at the top of the body of a page. Any styling with header attached will change and not affect main, footer, or div.
    • As with HEADER, the same can be said for MAIN and FOOTER
