About Absolute and Relative Links

Absolute links and relative links are different in that relative links can update when changes are needed.

Absolute links can only have one domain name so it won't work if we try to update.

Relative links is less typing.

3 Rules of Relative Links

  1. Sibling - Make files siblings by keeping them in the same directory.
  2. Child - Have files or directories be part of the same parent folder.
  3. Aunt or Uncle - use ../___.html and let the program figure out what folder/file to access.
