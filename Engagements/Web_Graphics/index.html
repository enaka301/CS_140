Answers to Questions

What kind of photos are good to encode using JPEG?
JPEG is used for complex, detailed digital photographs and realistic images with smooth color gradients. Real life pictures.
What kind of photos are good to encode using GIF?
Pictures that have moving components. Simple graphics that can loop.
What is unique about the PNG format?
It offers lossless compression, supports transparent backgrounds, and can support up to 16 million colors.
How do you resize your photo to the size it should be displayed?
You can change the size of the photos by editing their pixels. You can use a photo editing software to do so.
Why should you resize photos using photo editing software instead of resizing it using CSS?
Using CSS only temporarily changes the images. On the screen it looks changed but in actuality it is not. Using software will permanently change the file's actual size and dimensions.
