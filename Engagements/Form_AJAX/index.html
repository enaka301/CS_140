Questions and Answers

What is AJAX?
Ajax is short for asynchronous java script and xml. This is a technique that simplifies building interactive sites.
Why do you put your JS Code in a separate file?
Putting JS Code in a separate file will help with maintenance, organization, and simplicity. No cluttered index.html.
How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error?
The dev tools can spot and pause on errors, display the error location, and show what line the error is on in the file. It shows it in the sources tab on breakpoints. Its a debugger online. Console can also check for errors too by putting alerts or flags to there.
Do your form and fields have the same ids that your JavaScript uses? Does the Console show any errors? List your ids, and fix any errors before you submit.
The form does use IDs that are the same for JavaScript. Without it, connection errors for data acquisition would occur. IDs that I have for form data are age, birthdate, name, email, and password.
