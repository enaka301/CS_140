What is JavaScript? How did it get its name?
JavaScript or JS is code used to make websites and pages interactive. It was a scripting tools made for developers on Netscape. Over time, it rebranded as a marketing ploy to JavaScript. Now everyone is confused when Java and JavaScript is mentioned together.
What are the two ways you can run JavaScript?
Two ways to run JS is either through a web browser or on a server.

How does your code prevent the form from being submitted? Why do we need to prevent it?
event.preventDefault() is code that cancels the browsers attempts to submit. It still submits but won't follow through.
