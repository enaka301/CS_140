Structural Tags

Structural Tags (HEADER, NAV, MAIN, FOOTER)

  • – Header is a tag that puts information at the top of the page
  •       Mainly for page navigation.
  • – Nav is the navigation bar that can go anywhere in the body/header.
  •       Uses links to go to other pages.
  • – Main tags help to contain content that is unique and the focus of a page.
  •       Helps to group content.

HTML Validation

– Used to ensure that there are no errors in HTML code.

Footer
